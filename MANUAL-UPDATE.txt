# Study World update v2 — sleep tracking, streaks, settings tabs, AI setup help

This update adds: sleep schedule tracking and study streaks on Today, Settings
as tabs (minimal scrolling), empty production workspaces (no demo data),
clearer signup/login messages, AI paste setup diagnostics, and refreshed
guides. Your saved progress is kept — this replaces code, not data.

## Before updating

On the browser where you currently study, open **Settings → Your data → Export
backup**. Keep that JSON file safe. Do not clear site storage.

## 1. Get the code

Use the GitHub **Download ZIP** button on this update's pull request or branch,
or pull the branch if you use git. Do not upload the ZIP itself to Render or
GitHub's file editor — unpack it first.

## 2. Upload / deploy

Copy the extracted files over your project (source, scripts, config, docs).
Your `.env` (if any) and `node_modules` stay untouched. Then:

```bash
npm ci --include=dev
npm run build
```

If you deploy on Render with the provided `render.yaml`, the build command is
already `npm ci --include=dev && npm run build` and the start command is
`npm start`.

## 3. Optional AI paste — environment variables

In Render → your service → **Environment**, set BOTH:

- `OPENROUTER_API_KEY` — your `sk-or-…` key (stays on the server)
- `AI_IMPORT_ACCESS_CODE` — a private code of 16+ characters (this is what you
  type into the app's dialog; it is NOT the API key)

Generate one with:

    node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"

Check `https://YOUR-SITE/api/targets/status` — `"configured": true` means the
AI paste works. If false, the `missing` list names exactly what to set, and the
app's paste dialog shows the same names.

## 4. After updating — quick checks

1. New signup email mentions the one-time code (OTP).
2. A fresh workspace starts empty ("Your world begins here").
3. Today → log last night's sleep; save a streak.
4. Settings → six tabs, one screen each.

Keep periodic JSON backups from Settings → Your data — they are the reliable
way to move work between browsers.
